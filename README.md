# The Wedding Ledger

A planning site for an engagement (Nov 2026) and a subtle Javanese-adat wedding (2027).
Javanese bride, Buginese groom — full adat sequence (siraman, midodareni, akad, panggih, resepsi).

- **Live page:** see the GitHub Pages link in the repo's *About* section.
- **`index.html`** — the website (also `wedding_plan.html`, identical).
- **`Wedding_Budget.xlsx`** — the working model: every line item is a live formula. Change any
  blue cell on the **Assumptions** tab and all tabs recalculate.
- **`build_xlsx.py`** — regenerates the workbook.

All figures are in Rp million. Angpau/gift money is not modelled — treat it as upside.
